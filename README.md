# Study Kasus 1 — Make Sense of Data with Analytics and AI

## Permasalahan
PT Maju Bersama mengalami kenaikan pendapatan, tetapi laba bersih menurun dan piutang meningkat. Tim perlu memeriksa biaya dan status pembayaran sebelum menentukan tindakan.

## Tujuan
Menghasilkan ringkasan deskriptif: total pendapatan, biaya, laba, piutang, serta pelanggan dengan piutang tertinggi. Contoh ini menunjukkan alur data → informasi → insight → keputusan.

## Menjalankan
```bash
python main.py
```
Data yang digunakan berada di `sales.csv` dan merupakan data sintetis.
