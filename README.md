# Study Kasus 5 — HCI & Data Visualization

## Permasalahan
Pengguna perlu melihat kondisi penjualan dengan cepat tanpa membaca tabel panjang. Dashboard menampilkan ringkasan utama, tren pendapatan, perbandingan biaya dan laba, serta filter bulan.

## Prinsip HCI yang diterapkan
- Ringkasan penting ditampilkan terlebih dahulu.
- Filter bulan disediakan agar pengguna bisa mengeksplorasi data.
- Grafik diberi judul dan label yang jelas.
- Tampilan dibuat sederhana dan tidak menggunakan dark pattern.

## Menjalankan
```bash
streamlit run app.py
```
Data pada dashboard merupakan data sintetis.
