# Study Kasus 3 — GIS untuk Pertanian

## Permasalahan
Kelompok tani ingin membandingkan beberapa lokasi berdasarkan koordinat, curah hujan, dan kemiringan lahan. Data contoh ini digunakan untuk latihan pengolahan atribut lokasi, bukan rekomendasi penggunaan lahan resmi.

## Tujuan
Menghitung skor kesesuaian sederhana dan mengurutkan kandidat lokasi. Konsep ini dapat dikembangkan menjadi proyek GIS dengan QGIS, PostGIS, GeoJSON, atau web map.
